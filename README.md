## 어디에 넣을지 결정하는 기준

실습의 핵심 목적을 기준으로 한 곳에 저장합니다. 사용 라이브러리보다 배우는 주제가 우선입니다. 다른 분야와 겹치면 Notebook에 관련 경로를 적으며 동일 파일을 여러 폴더에 복사해 관리하지 않습니다.

| 과제 예시 | 위치 |
|---|---|
| Pandas 결측치·중복 처리 전후 비교 | `data-analysis/preprocessing/` |
| Pandas 문법·groupby·merge 연습 | `data-analysis/pandas/` |
| Precision·Recall·임계값 비교 | `evaluation/imbalance-thresholds/` |
| PyTorch 학습 루프 자체 연습 | `pytorch/training-loops/` |
| PyTorch로 CNN 구조·이미지 분류 학습 | `computer-vision/cnn-classification/` |
| YOLO 결과의 IoU·mAP 평가 | `computer-vision/object-detection/` |
| 시계열 시간 순서 분할과 누수 확인 | `time-series/data-splitting-leakage/` |
| 정제부터 학습·API까지 통합 구현 | `projects/<프로젝트명>/` |
| 기존 코드 리뷰·디버깅·테스트·리팩터링 | 원래 실습 또는 프로젝트 폴더에서 개선하고 Notebook·학습 기록에 이유 기록 |

## 파일과 기록 규칙

- 학습 코드의 기본 형식은 Jupyter Notebook(`.ipynb`)입니다. 설명·코드·결과·해석을 셀로 나눕니다.
- 파일명 예: `001_missing_values_duplicates.ipynb`. 번호는 각 하위 폴더의 정리 순서이며 주차나 의무 진도가 아닙니다.
- 데이터는 해당 실습 옆의 `data/`에 필요할 때 둡니다. 큰 데이터는 출처와 다운로드 방법을 Notebook에 기록합니다.
- 여러 파일을 쓰는 한 실습은 해당 주제 폴더 안에 실습 이름의 폴더로 묶을 수 있습니다.
- 학습 진행은 기존 `learning-log/progress.md`를 유지하고, 일일·주간·단계별 기록은 각 하위 폴더에 둡니다.
- 공개할 결과의 목적·데이터·실행법·결과·한계·재현 환경을 적습니다.
- 계획 문서의 최신 원본은 Google Drive에서만 관리합니다. 이 README는 저장 위치 안내이며 계획 사본이나 대화 동기화 문서가 아닙니다.

현재의 역량 목록에 없는 새 분야는 실제 학습 주제가 확정되면 적절한 하위 폴더를 추가합니다.
