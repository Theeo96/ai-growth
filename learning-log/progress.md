# AI 역량 강화 진행 상태

이 파일은 ChatGPT 예약 리마인드가 진도를 임의로 넘기지 않도록 사용하는 진행 추적용 기준 파일입니다.

## 현재 과제
- 상태: 미완료
- 과제: Python Notebook에서 작은 데이터의 결측치·중복 확인과 처리 전후 비교
- 최소 수행: 20분
- 표준 수행: 40~50분
- 완료 증거:
  1. ai-growth 저장소에 과제와 직접 관련된 새/수정 .ipynb가 커밋되어 있음
  2. Notebook에 결측치와 중복 확인이 포함되어 있음
  3. 간단한 처리 후 전/후 비교가 포함되어 있음
- 완료 후 다음 단계: 예약 리마인드가 새 과제를 만들기 전에 이 파일 상태를 완료로 갱신

## 진행 판정 규칙
- 사용자의 명시적 완료 보고 또는 GitHub의 명확한 완료 증거가 있을 때만 완료 처리
- 단순 파일 생성, 관련 없는 커밋, 오래된 커밋만으로는 완료 처리하지 않음
- 완료 증거가 없으면 다음날에도 같은 과제를 유지
- 로컬 Codex 폴더는 예약 작업이 직접 확인할 수 없으므로 GitHub를 외부 확인 기준으로 사용
- 15시까지 완료 증거가 없으면 18시 리마인드를 더 직접적인 재개 메시지로 전환
- 20시까지 미완료면 다음날 09시에도 같은 과제를 유지
